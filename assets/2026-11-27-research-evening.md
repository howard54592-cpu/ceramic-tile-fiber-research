### 1. ⭐⭐⭐⭐⭐ NASA **烧蚀建模能力全景**（`20220016583`，2022-11-11，Ames，PRESENTATION）

> 来源：NTRS `20220016583`

- 摘要要点：面向近期与未来 NASA 任务的科学载荷与载人投送目标，伴随**挑战性且复杂的入轨/再入**；需要**先进烧蚀 TPS 材料**，因此**稳健的烧蚀建模能力**是评估性能的关键 —— 其作用是**弥合地面试验与入轨条件之间的巨大鸿沟**。
- 传统烧蚀建模工具集 = **连续体热/材料响应分析**；近期已扩展到包含**高保真、多尺度、多物理**技术，以更完整描述烧蚀中丰富的物理与化学。
- 该报告是对 NASA 内部烧蚀建模**当前技术能力与工具的快照**，并覆盖：**学术界在支撑该技术域演进中的角色**、以及**内外部投入如何交汇到即将到来的任务**上以降低风险。
- **工程价值**：⭐⭐⭐⭐⭐ —— 这是**能力级而非论文级**的元数据，把「烧蚀材料 / 烧蚀机理 / 烧蚀试验」三条此前分散的技术线（v1.238 弧风洞工质、v1.237 在途测量、v1.235 KCMA 互换校准）统一到一个**机构能力框架**下。
- ⭐⭐⭐⭐⭐ **一条方法学论断可直接引用**：**烧蚀建模能力 = 弥合「地面试验 ↔ 入轨条件」鸿沟的手段** —— 这把「为什么要建更好的模型」与「为什么地面试验不能直接外推」明确绑定，正好回答了本领域长期存在的「试验数据不可比 / 外推不可靠」问题（承 v1.232 NESC bake-out >6× 分歧、v1.235 跨设施数据不可比）。
- ⭐⭐⭐⭐ **与 v1.238「地面试验设施三层分级」合看**：设施只是 L2/L3，而**建模能力是把 L2 数据合法升级为 L3 结论的唯一通道** → **「设施层级」与「建模层级」必须成对设计**，单建设施不建模型 = 仍然无法认证。

### 2. ⭐⭐⭐⭐⭐ **ARCTRON：多模态 + 磁化的再入等离子体实验室**（`20250009613`，2025-11-21，Ames）

> 来源：NTRS `20250009613`

- 摘要要点：ARCTRON 是研究**等离子体-材料相互作用与流动物理**（与航天器再入相关）的新平台。
- **多模态加热**：**2 kW 感应耦合等离子体（ICP）炬** 与 **弧风洞** 并联 + **2 kW 蓝光激光** 辐射加热 + 石墨加热元件（温度控制上限 **1000 °C**）。
- **磁化**：水冷磁力线圈提供**最高 0.1 T**，用于研究**磁流体动力学（MHD）效应**；**6 工位 2 轴运动**的 sting arm 实现试样与诊断仪器的精确定位。
- **工质灵活**：可在 **Ar / 空气 / CO₂ / O₂ / N₂ / He** 运行 → 覆盖惰性与反应性等离子体环境。
- **诊断套件**：Argon LIF（流速/温度）、LAS（原子氧）、Shamrock 500i 光谱仪、 pyrometer、相机；**原位诊断**包括扫掠 Langmuir 探针、量热计、嵌入式热电偶。
- **五个首批研究方向**：① 高温表面催化性 ② 多物理模型验证 ③ 电极侵蚀 ④ 磁屏蔽与流动控制 ⑤ **MHD 弧稳定性**。
- **工程价值**：⭐⭐⭐⭐⭐ —— 与 v1.238 的 **HYMETS 弧风洞改用 CO₂ 工质**形成**同一主题的两端**：
  - **HYMETS 解决的是「用什么工质代表火星大气」**；
  - **ARCTRON 解决的是「一次试验里同时变工质、变磁场、变加热方式」** → 即**参数空间的正交化**。
- ⭐⭐⭐⭐⭐ **一条能力建设结论**：HYMETS 是**专用化**（一个设施锁死一个工质），ARCTRON 是**通用化**（一个设施覆盖整个工质空间）→ **专用设施的极限是「只能认证 CO₂ 轨迹」，通用设施的极限是「每种工况都不是最纯粹的」**；两者互补而非替代。
- ⭐⭐⭐⭐⭐ **「电极侵蚀」与「MHD 弧稳定性」被列为首批研究方向** —— 这两项**不是材料学问题而是等离子体源本身的问题**，直接决定该设施能跑多少次试验而不失效 → **试验设施的寿命本身是一项需设计的指标**（承 v1.238 IPM RAS「单试样可做最多 100 次 15 min 循环」的能力上限问题）。
- ⭐⭐⭐⭐ **「磁屏蔽」入列** —— 对返回式/可重复使用平台的 TPS 设计有直接影响：**等离子体本身可被偏转** ⇒ 加热环境可被工程手段整形，而不只是被承受。

### 3. ⭐⭐⭐⭐⭐ **星火 SRB 尾裙「热屏幕帘」全尺寸试验**（`19850026908`，1980-06-01，NASA-CR-170883，Legacy CDMS）

> 来源：NTRS `19850026908`；报告号 `NASA-CR-170883` / `LMSC-HREC-TM-D697896` / `NAS 1.26:170883`

- 摘要要点：**全尺寸**（full scale）段落的**真实固体助推器（SRB）尾裙热屏幕帘**在 **MSFC 大型辐射灯设施（LRLF）** 试验。
- **幕帘按 SRB 上的实际安装方式水平安装**；专门设计并使用**振动台（shaker rig）** 施加运动，**模拟飞行中由运载器声学（vehicle acoustics）引起的运动**；用**热电偶**监测幕帘材料温度。
- **同时施加了上升段（ascent）与再入（reentry）两种热载荷**。试验装置各方面均按预期工作，试验宣告成功。
- **工程价值**：⭐⭐⭐⭐⭐ —— 本领域极少见到**「隔热/热防护结构 + 声学振动 + 双工况（上升/再入）」三者同时考虑**的地面试验：
  - 几乎所有 TPS 文献把**热载荷**与**力学/振动载荷**分开处理；
  - 这里明确指出**幕帘在飞行中会被声学激励摇动**，因此**热边界条件在振动下是非稳态的**。
- ⭐⭐⭐⭐⭐ **一条可复用的试验设计原则**：**当结构在飞行中会动，热测试必须复现这个运动** —— 否则测出的「材料在动」与「材料不动」的温度分布可能不同；且**上升与再入两种热载荷应合并在同一试件上施加**（因为同一件幕帘要经历两次）。
- ⭐⭐⭐⭐ **「声学剥落」与「污染」的耦合**：SRB 尾裙幕帘与外贮箱喷涂泡沫（SOFI）是**同一类声学剥落问题**（见本场第 9 条 `20160005657`）→ **「泡沫剥落 → 污染下游热控面」是一条跨 35 年的连续链**（承 v1.235 记录的技术迁移价值）。

### 4. ⭐⭐⭐⭐⭐ **外贮箱闭孔泡沫低温热膨胀定量数据**（`20060047492`，2006-01-01，MSFC，CONFERENCE_PAPER）

> 来源：NTRS `20060047492`；作者 Stokes, Eric

- 摘要要点：航天飞机**外贮箱（ET）** 装液氢燃料与液氧氧化剂，向轨道器三台主发动机供给。ET 的热防护系统 = **喷涂泡沫绝缘（sprayed-on foam insulation）+ 预制烧蚀材料**。
- **闭孔泡沫是 ET 的外覆层**，其职责是**尽量减少佛罗里达潮湿空气中凝结并冻结在贮箱上的水分**（发射前带低温推进剂待发状态）。
- **四种特种闭孔泡沫**用于贮箱；本报告测量其中**三种聚氨酯/聚异氰脲酸酯泡沫**的热膨胀（收缩）：**−423 °F（液氢温度）到 +125 °F**，在**大气条件与真空下**均测。
- 三种材料：**NCFI 24-124**（机械贴敷，覆盖贮箱主要面积，占泡沫总量的 **77%**）、**BX-265**（机械贴敷 + 手工喷涂，用于「closeout」区域）、**PDL 1034**（手工浇注，填充不规则空腔）。
- 测量方式：前两种材料在**三个主材料方向**、后一种在**两个主材料方向**，均**三重复**；Task 1 专门开发**均匀升温速率、尽量减小轴向与径向热梯度**的试验技术，试件中**四个位置**测温。
- **工程价值**：⭐⭐⭐⭐⭐ —— 这是**极少见的、带具体温度区间与真空/大气双环境的泡沫热膨胀实测数据**，直接可支撑低温贮箱与低温推进剂绝热设计。
- ⭐⭐⭐⭐⭐ **关键定量结论**：**闭孔泡沫的首要功能不是「隔热」而是「防潮结冰」** —— 摘要明确定位其职责为**减少凝结冻结的水分**（佛罗里达湿度空气 + 低温推进剂）。→ **绝热设计的第二条功能线：绝热层必须同时是「水分屏障」** —— 一条常被气凝胶/MLI 选型讨论忽略的约束（MLI 与气凝胶在防结冰上是弱项）。
- ⭐⭐⭐⭐⭐ **一条试验方法学要点**：**「均匀升温速率 + 最小化轴向/径向热梯度」本身是一项被单独列为 Task 1 的技术难点** —— 说明**低温热膨胀数据的说服力完全取决于温度场的均匀性**；这与 v1.235「KCMA 数值重建必须解耦表面退蚀与内部物理」是同一类方法学自觉：**先证明你的试验场是干净的，再谈材料属性**。
- ⭐⭐⭐⭐ **材料配比的三分法 = 施工方式的三分法**：机械贴敷（77%）/ 机械+手工喷涂 / 手工浇注 → **「同一材料族 + 三种施工工艺 → 三种不同的可建模性」**，材料报告必须同时给出工艺维度。
- ⭐⭐⭐ **与本场第 8 条（CRYOTE）合看**：**低温推进剂绝热的「材料（泡沫/MLI/气凝胶）→ 施工 → 试验设施」三段在本领域是分离的**，这一条同时给出了材料+工艺+试验技术三者的**对接点**。

### 5. ⭐⭐⭐⭐ **可伸展热盾再入飞行器气动稳定性**（`19980227404`，1961-08-01，NASA-TN-D-892 / L-1329，HQ）

> 来源：NTRS `19980227404`

- 摘要要点：低速研究测定**带可伸展热盾（extensible heat shield）的再入飞行器**的静稳定与振荡稳定导数（纵向与横向），用于**大迎角再入**。
- **工作原理**：热盾**向前伸展**以给出所需的气动中心位置（大迎角再入）；**再入段完成后热盾回收**，给出滑翔飞行小迎角下的稳定性与配平。
- 结果（再入构型，近 90° 迎角）：纵向与方向静稳定、**正上反效应（positive dihedral）**、**滚转有正阻尼、偏航阻尼为零**。
- 结果（着陆构型）：在试验迎角范围内俯仰/滚转/偏航**均具正阻尼**，但**方向不稳定**，且在 **10°~20° 迎角**间**负上反效应**。
- **工程价值**：⭐⭐⭐⭐ —— 一个**被现代 TPS 讨论完全遗忘**的设计范式：**把热盾本身作为可变几何面，用来同时管理「再入热防护」与「再入气动稳定性」两个目标**。
- ⭐⭐⭐⭐⭐ **与本场其他发现构成一条意外主线** —— **「几何」作为一种 TPS 手段**：
  - `19980227404`（1961）：**热盾几何**（伸出/回收）→ 管住气动稳定性；
  - `19700032315`（1967，US 3,301,507）：**热盾气动外形**（纵向与方向稳定性）→ 同源；
  - v1.237 `US8714091`（错缝接头）：**接缝几何**（错开热流路径）→ 管住瓦缝热桥；
  - v1.237 `EP3321191B1`：**紧固件-TPS 一体化** → 管住结构热桥；
  - v1.238 弧风洞工质（CO₂）：**工质选择** → 管住认证代表性；
  - → **统一形式语言：「热防护问题的三个可动杠杆 = 材料 / 结构 / 拓扑（几何、工质、装配关系）」**，其中**几何与拓扑被系统性低估**。
- ⭐⭐⭐⭐ **「热盾回收」带来的构型切换是双刃的**：本条数据明确显示**着陆构型在 10–20° 迎角方向不稳定且负上反** → **热防护结构引入了一个只在特定飞行段出现的气动稳定性问题**，而这个问题**与热流分布无关、纯粹来自几何变更**。这条对任何考虑「可变几何 TPS」的现代方案（可展开热盾、可调隔热）是**直接的警告性先例**。

### 7. ⭐⭐⭐⭐ **OSIRIS-REx MLI 毯阳光入射热评估**（`W2750031114` 2017-09-05 / `W3166724615` 2017-08-06，同源版本对）

> 来源：OpenAlex；`W2750031114` = SPIE *Astronomical Optics*，DOI `10.1117/12.2276642`；`W3166724615` = NASA STI Repository 记录；作者 Michael K. Choi

- 要点：OSIRIS-REx 于 **2016-09-08** 入轨，飞往近地小行星 **(101955) Bennu**。
- **在出程巡航（Outbound Cruise）标称姿态下（太阳在 +X）**，阳光入射到：**OCAMS PolyCam 遮阳罩 MLI（微孔黑色 PTFE）**、**PolyCam 光学支撑管的一段（MLI + 锗黑 Kapton / GBK）**、**OTES 遮阳罩（MLI+GBK）**、**IMU 遮阳罩（MLI+GBK）**、**OLA 激光测高计遮阳罩（MLI+GBK）**。
- **关键机制**：阳光被上述 MLI **反射或散射**到前甲板（+Z）的其他部件上，**并照亮整个前甲板** → **MLI 既是隔热体，也是「二次光源」**。
- 已对**小行星近地操作、TAG（touch-and-go）采样获取、返回巡航**三个飞行阶段完成详细太阳入射热评估；分析使用了**出程巡航飞行温度遥测**与 **`USM_3_DPC_0_CURRENT` 飞行电流遥测**数据。
- **工程价值**：⭐⭐⭐⭐ —— 本领域**极少有 MLI 表面光学-热耦合的实飞数据**：
  - MLI 设计流程几乎全是**纯一维热学优化**（层数/覆盖率/镀铝），**从不做「MLI 镀铝层的反射率 → 环境光学污染 → 相邻光学部件升温」这条链**；
  - 光学 MLI 用 **GBK（锗黑 Kapton）** 还是 **微孔黑色 PTFE** 决定了它**散射还是吸收**太阳光 —— **同一种「黑色 MLI」在热学与光学上是两个不同的设计问题**。
- ⭐⭐⭐⭐⭐ **一条新规则**：**凡搭载相机/光谱仪/激光雷达的航天器，其 MLI 选型必须同时给出「太阳反射/散射谱」这一光学参数**，否则 MLI 会成为一个未被建模的**二次热源**（把太阳光从「被绝热的表面」搬到「旁边未被绝热的仪器」上）。这条与 v1.238 `10.1109/temc.2016.2616121`（MLI 搭接/引出方式改变屏蔽效能）**共同构成本领域被系统忽略的两条 MLI 交叉耦合：电磁耦合 + 光学耦合**。

### 8. ⭐⭐⭐⭐ **CRYOTE 低温轨道试验台地面件最终报告**（`20150022115`，2015-10-01，NASA/TM-2015-218827，Glenn）

- ⭐⭐⭐⭐⭐ **一条选型结论**：**「绝热体类型」与「推进剂管理策略」是耦合的，不是独立的**。选择泡沫还是 MLI，等于选择「沉降式飞行」还是「可加速/可俯冲飞行」→ **在长寿命与高轨道能量任务中，MLI 的性能优势会转化成任务性能优势**。这条与 v1.237「PCM 用于航天时相变体积变化小与熔化均匀同等重要」属同一族结论：**绝热材料的性能指标必须与「系统级约束」一起读**。

## 改进点

1. ⭐⭐⭐⭐⭐ **新增渠道规则 —— `patents.google.com` 的失败态需按 HTTP 码分型**：本场 xhr 开场即 **429 + 1,453 B**（v1.238 记录的是「先成功后 503 + 1,103 B」）→ **两种壳体字节数不同（1,103 vs 1,453），应分别识别**：1,453 B = Google Error 429 robot 页；1,103 B = "sorry…" 自动查询封锁页。**两者都是 IP 级封锁，退避无效**。
2. ⭐⭐⭐⭐⭐ **新增专利轴 —— NTRS `otherReportNumbers` 是独立可用的专利检索通道**：本场在 Google Patents 全灭的情况下仍挖出 13 个专利标识（含 US 3,301,507 等）+ NASA-CASE 编号。**下一场应把 `Patent Number` / `Patent Application Number` / `NASA-CASE` 显式加入 NTRS 检索词面**，并把它列为常驻专利轴。
3. ⭐⭐⭐⭐ **arXiv listing 的「HTTP 200 + 小字节数 + 0 ID」必须单列为第四失败态**（本场 app-ph 首轮 1,034 B 截断页）：v1.215 已定义「可达但空 / 伪成功 / 外壳限流」三态，**本场实测到第四态 = 「HTTP 200 + 页面被截断（字节数小但 >0）+ 提取 0 ID」** → 处置 = **重试 1 次**（本场一次成功），且**每场必须断言 ID 数 > 0**。
4. ⭐⭐⭐⭐ **Semantic Scholar 的 429 与 proxy 无关**：直连 429、经 proxy 也 429 → **S2 是本机出口 IP 的独立速率限制**；本场 2/5 恢复率。**下一场应把 S2 组数压到 2–3 组并加组间 8–10 s 间隔**（与 OpenAlex 同纪律），而非期望它成为主力。
5. ⭐⭐⭐⭐ **NASA wp-json 走 proxy、直连 429**（本场实测）→ 与 v1.236/v1.237 的路由表一致，**继续沿用 proxy**。
6. ⭐⭐⭐ **ESA RSS 通道应正式停用**：本场返回 **HTTP 404 + 149,435 B 壳**（连「可达但空」都不是，是路径失效）。连续 5+ 场零产出，**建议从常驻通道清单移除**，改为「仅当发现 ESA 专题新闻线索时定点访问」。
